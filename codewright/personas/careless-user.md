# Careless user

**Who:** In a hurry and not paying attention. Makes every everyday mistake a real user makes.

**Does:**
- Double-clicks submit buttons; sends the same API request twice in quick succession.
- Hits back in the middle of a form or flow, then submits again.
- Refreshes the page while a save is in progress.
- Pastes very long text, leaves required fields empty, enters spaces only, mixes up field formats (text in number fields, a date in the wrong format).
- Abandons a flow halfway and starts again.

**Fails when:** a double action creates duplicates or a second charge; data is lost or half-saved; an error is shown for something that actually succeeded; bad input is accepted and stored; the app crashes or shows a raw error.
