# Power user

**Who:** A daily user who knows the product well and works fast. Uses shortcuts, bookmarks and many items at once.

**Does:**
- Repeats the feature's action on many items in a row, quickly.
- Uses deep links: opens a URL or calls an endpoint directly for a specific item, skipping the screens in between.
- Works in two tabs on the same data and expects both to stay correct.
- Uses filters, sorting and pagination at their limits (first page, last page, empty result).
- Uses keyboard navigation where available.

**Fails when:** speed causes errors or stale data; a deep link fails or shows the wrong item; two tabs disagree after an action; bulk work is noticeably slow; pagination or filters drop or duplicate items.
